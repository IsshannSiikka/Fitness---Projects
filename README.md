🏋️ Fitness Tracker (Python CLI App)

A command-line fitness tracker app built with Python.
It helps you log workouts, analyze weekly progress, visualize performance, and even get AI-based tips to optimize your training.

✨ Features

📅 Add workouts with pushups, pullups, HIIT minutes, calories, and body part trained

📊 Weekly summary of total/average pushups, pullups, calories burned

💡 AI tips to improve workouts (rule-based insights)

💾 Save & load data from CSV file (your workouts are never lost)

📈 Graphs & analytics using matplotlib

🎨 Beautiful CLI UI with colors using Rich

⚙️ Installation

Clone the repository:

git clone https://github.com/your-username/Fitness-Tracker.git
cd Fitness-Tracker


Install dependencies:

pip install -r requirements.txt


Run the app:

python tracker.py

📦 Requirements

Create a requirements.txt file with:

matplotlib
rich
